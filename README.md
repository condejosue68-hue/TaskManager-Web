
# TaskManager Web

## Descripción
TaskManager Web es una aplicación web sencilla que permite organizar actividades y llevar un control de tareas pendientes. El usuario puede agregar nuevas tareas, marcarlas como completadas y eliminarlas.

## Objetivo
Desarrollar una aplicación web funcional aplicando conocimientos de HTML, CSS, JavaScript y control de versiones mediante Git y GitHub.

## Funcionalidades
- Agregar nuevas tareas.
- Marcar tareas como completadas.
- Regresar tareas a estado pendiente.
- Eliminar tareas.
- Validar que no se agreguen tareas vacías.
- Diseño responsivo para diferentes tamaños de pantalla.

## Instrucciones de ejecución
1. Descargar o clonar el repositorio.
2. Abrir la carpeta TaskManager-Web en Visual Studio Code.
3. Abrir el archivo index.html con Live Server.
4. Utilizar el formulario para registrar nuevas tareas.

## Flujo de trabajo GitHub Flow
Se utilizó GitHub Flow para organizar el desarrollo colaborativo.

Se creó una rama principal llamada main y ramas independientes para desarrollar las funcionalidades:

- feature/interfaz
- feature/tareas
- feature/estilos

Cada rama tuvo commits independientes y posteriormente se integró mediante Pull Requests, permitiendo revisar los cambios antes de fusionarlos.

También se realizó una prueba controlada de conflicto entre dos ramas, modificando la misma línea del archivo index.html. El conflicto fue resuelto manualmente y registrado mediante un commit.
